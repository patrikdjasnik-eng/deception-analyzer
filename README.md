# Deception Analyzer

Projekt pro analýzu textu a vyhodnocení možných známek klamavého nebo manipulativního obsahu.

Projekt je vyvíjen s důrazem na čistý kód, přehlednou strukturu a zachování původního vzhledu aplikace.

## Stav projektu

Aktuálně probíhá příprava čistého základu repozitáře. Další vývoj bude navazovat na původní frontend a jeho požadavky.

## Pravidla vývoje

- názvy kódu a technických prvků jsou v angličtině
- komentáře v kódu jsou česky a pouze tam, kde mají smysl
- commit messages jsou česky
- technická dokumentace zůstává stručná
- do repozitáře nepatří secrets, build artefakty ani lokální prostředí
- vzhled původní aplikace se zachovává 1:1
